# BOAT AI 予想サイト Ver.6

## 主な機能
- 公式出走表・直前情報・3連単オッズの取得
- 過去データによる場別補正
- 120通りの期待値分析
- 適応学習（実結果を使った軽量な重み補正）
- バックテスト
- **実戦収支管理**：投資額、払戻、損益、回収率、的中率、連敗、月別成績
- 収支データは `performance_ledger.json` に保存

## 起動
```bash
pip install -r requirements.txt
python app.py
```
ブラウザで `http://127.0.0.1:8000` を開いてください。

## 注意
予測・期待値・過去データ補正・バックテスト・収支指標は将来の結果や利益を保証するものではありません。公式情報を確認し、無理のない範囲で利用してください。
