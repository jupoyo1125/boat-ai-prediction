# 発売前の本命・対抗一覧

`GET /api/analyze` に `view=ranking` を指定すると、同じ公式出走表・展示情報・前日までの履歴・学習済みモデルで評価順だけを取得できる。

通常と同じ `date`, `stadium`, `race`, `fixed`, `history_days` を使用する。レスポンスは `ranking_only: true` と対象の日付・場・レース番号を含む。`main` が本命、`second` が対抗。2艇をまとめて「軸」と表示する際は、その定義を明記する。

この表示ではオッズを取得せず、`bets` は空配列、`odds_count` は0になる。保存・学習・公開投稿は行わない。取得時点の展示情報があれば同じ評価計算に反映されるため、展示前資料には6艇の展示値が未公開であることを確認し、取得時点を記載する。

通常の予想処理と展示後の自動予想は従来どおり、正しく取得したオッズが必要。`view` を指定しない既存クライアントの評価・買い目・保存条件は変更しない。
